STEP 0 — SUPABASE HEALTH CHECK (run this SQL first)
------------------------------------------------------
select table_name,
       case when table_name in (
         select table_name from information_schema.tables
         where table_schema = 'public'
       ) then 'EXISTS' else 'MISSING' end as status
from (values
  ('enquiries'), ('sections'), ('calendar_events'), ('announcements'),
  ('attendance'), ('homework'), ('section_photos'), ('fee_assignments'),
  ('fee_structures'), ('staff'), ('academic_years'), ('child_kit'),
  ('programme_items'), ('child_documents')
) as t(table_name)
order by table_name;

If child_documents shows MISSING, run the SQL provided separately to create it.
